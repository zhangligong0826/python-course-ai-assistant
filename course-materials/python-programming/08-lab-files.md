# 实验 2：文件处理与异常恢复

## 实验目标

完成一个 CSV 成绩文件分析器，练习 pathlib、UTF-8 文件读写、字典统计、异常捕获和资源关闭。

## 文件格式

输入文件每行格式为 name,score，例如 Alice,90。允许空行；姓名不能为空；分数必须是 0 到 100 的整数。文件可能不存在、编码错误或包含格式不完整的行。

## 建议步骤

1. 写 parse_row(line, line_number)，返回姓名和分数，错误时抛出带行号的 ValueError。
2. 写 load_scores(path)，使用上下文管理器逐行读取 UTF-8 文件。
3. 写 group_by_level(records)，按 90/60 两个阈值分为优秀、及格和待提高。
4. 写 write_report(path, summary)，将统计结果写入新文件，不覆盖原始输入。
5. 为文件不存在、空文件、重复姓名和坏行增加测试。

## 验收标准

- 输入文件始终以 UTF-8 打开，并在报告中说明路径。
- 坏行被记录为可读错误，其他合法行仍能处理。
- 不使用裸 except 隐藏未知异常。
- 文件由 with 或等价方式关闭。
- 原始输入文件保持不变，输出文件路径由参数明确指定。

## 思考题

- 为什么相对路径会随当前工作目录变化？
- 为什么要捕获 ValueError 而不是所有异常？
- 如何在大文件上避免一次性读取全部内容？

## 学术诚信提示

可以请求助教解释异常类型和测试设计，但必须自己完成文件路径、错误处理和报告格式的取舍。
