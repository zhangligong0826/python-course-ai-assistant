# Python 程序设计课程资料

本目录是“Python 程序设计 AI 助教”的课程知识库源资料。资料按六章组织，包含课程讲义、实验指导、示例代码和常见错误说明四类内容。所有文件导入 Open WebUI 前必须完成代码检查、事实检查和来源登记。

## 章节范围

1. 基础语法：变量、基本类型、运算符、输入输出。
2. 流程控制：条件分支、循环、`break`、`continue`。
3. 函数：参数、返回值、作用域、递归基础。
4. 容器：列表、元组、字典、集合和推导式。
5. 文件与异常：文本文件、编码、异常捕获和资源关闭。
6. 面向对象：类、对象、属性、方法、继承和封装。

## 资料类型

- `lecture`：六份章节讲义。
- `lab_guide`：两份实验指导。
- `example_code`：可运行示例代码集。
- `error_reference`：常见错误与修复说明。

## 质量要求

- 资料正文使用稳定标题层级，便于 RAG 按章节检索。
- 代码示例必须通过 Python 3.12 语法检查；需要运行时行为的示例必须有测试。
- 课程资料中不包含学生个人信息、API 密钥或未经授权的教材全文复制。
- `materials-manifest.csv` 是导入前后的唯一清单；导入成功后将 `status` 更新为 `indexed`，并补充实际字数或页数列。
