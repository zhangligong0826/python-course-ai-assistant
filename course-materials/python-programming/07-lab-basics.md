# 实验 1：基础语法与流程控制

## 实验目标

完成一个“成绩统计器”，练习输入转换、条件分支、循环、函数和边界校验。实验重点是把问题拆成小函数，而不是追求代码长度。

## 环境与输入

Python 3.12。程序接收若干行成绩，每行是 0 到 100 的整数；输入 q 结束。空行、非数字和超范围成绩应给出提示并继续读取。

## 建议步骤

1. 写 parse_score(text)，将字符串转为整数并校验范围。
2. 写 read_scores()，循环读取数据，遇到 q 返回列表。
3. 写 summarize(scores)，返回数量、总分、平均分、最高分和最低分。
4. 写 format_report(summary)，以稳定格式输出报告。
5. 用空输入、单个成绩、全 0、全 100 和非法输入手工验证。

## 验收标准

- 合法成绩全部保留，非法输入不会让程序崩溃。
- 平均分使用浮点计算，保留两位小数。
- 空列表有明确结果，不能直接访问不存在的第一个元素。
- 计算逻辑可通过独立函数测试。
- 输出中不泄露任何学生个人信息。

## 思考题

- 为什么 input() 的结果必须先转换？
- 如果用户输入  90 ，应在哪一步去除空白？
- 如何让读取函数不依赖具体的终止字符？
