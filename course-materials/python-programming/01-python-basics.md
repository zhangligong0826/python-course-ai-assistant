# 第 1 章 Python 基础语法

## 学习目标

掌握变量、常用数据类型、运算符、类型转换和标准输入输出；能够读懂并编写短小的顺序执行程序。

## 核心概念

Python 变量是指向对象的名称，不需要先声明类型。常见基本类型包括 \`int\`、\`float\`、\`bool\` 和 \`str\`。\`=\` 是赋值，\`==\` 才是比较。字符串可以使用单引号或双引号，f-string 可插入变量。

    name = "Lin"
    age = 18
    height = 1.72
    is_student = True
    print(f"{name} is {age}: {is_student}")
    print(type(height).__name__)

常用转换：\`int("12")\`、\`float("3.5")\`、\`str(12)\`。输入函数 \`input()\` 始终返回字符串，进行数值计算前必须转换。

    first = int(input("first: "))
    second = int(input("second: "))
    print(first + second)

## 运算符

算术运算包括 \`+ - * / // % **\`；比较运算返回布尔值；逻辑运算为 \`and\`、\`or\`、\`not\`。除法 \`/\` 返回浮点数，\`//\` 是整除，\`%\` 是余数。表达式较复杂时用括号明确优先级。

## 易错点

- 把 \`=\` 写成 \`==\` 或反过来。
- 忘记 \`input()\` 返回字符串，导致字符串拼接而不是相加。
- 用 \`is\` 比较普通值；值比较应优先使用 \`==\`。
- 变量名使用关键字、包含空格或大小写混乱。

## 小结

顺序程序的基本路径是“获取数据—转换—计算—输出”。遇到类型错误时先检查每个变量的 \`type()\` 和输入转换位置。
