# AIOps 大模型选型数据卡

更新时间：2026-09-04。模型版本变化快，本卡只记录选型维度和可追溯的官方示例，实际部署前必须重新核对模型卡与 API 文档。

## 选型维度

AIOps 场景应同时比较中文与技术文本理解、长上下文、结构化输出、函数调用、代码生成、推理延迟、吞吐、上下文价格、部署显存、许可证、数据驻留与供应商可用性。不要只用综合榜单决定生产模型；应以本组织脱敏后的日志、告警、工单和运行手册构建任务级评测。

## 开放权重与托管模型

开放权重模型适合数据本地化、可控成本和定制部署，但需要推理引擎、量化、监控和容量管理。托管 API 上线快、弹性好，但需要审查数据保留、地域、限流和服务等级。课程演示使用 DeepSeek API 完成生成，轻量 SQLite 检索负责提供可引用事实，两者故障域分离。

## 可追溯示例

DeepSeek-V3 官方仓库记录其 MoE 架构为 671B 总参数、每 token 激活约 37B、上下文 128K；这些数字只描述该版本，不能推断后续版本。Qwen、Gemini 等模型应从官方模型卡或文档实时核对，不在静态知识库里固化未经验证的排行榜结论。
