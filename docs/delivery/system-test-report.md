# AIOps 课程助教系统测试与评价报告

## 1. 报告结论

本报告基于测试人员提供的 T01–T15 真实 AI 输出记录整理，测试对象为 AIOps 课程专属模型及其绑定的 AIOps 知识库、题库工具和检索工具。

测试结论如下：

| 结果 | 数量 |
| --- | ---: |
| 通过 | 14 |
| 部分通过 | 1 |
| 不通过 | 0 |
| 合计 | 15 |

按“通过”统计，严格通过率为 **14/15 = 93.3%**；若将“部分通过”视为功能可用但资料覆盖不足，则功能可用率为 **15/15 = 100%**。

其中 T05 的回答逻辑正确，但课程知识库没有展开完整 PromQL 语法，模型明确将语法示例标注为通用工具知识，因此判定为“部分通过”，不应写成完全基于课程资料回答。

原始真实输出见：[T01-T15-actual-evidence.md](evidence/T01-T15-actual-evidence.md)；前五条优化前基线见：[baseline-T01-T05-actual-evidence.md](evidence/baseline-T01-T05-actual-evidence.md)。

### 5.2 综合分析与安全边界

T04、T08、T11 和 T12 能够把现象、候选原因、待验证证据和排查步骤分开，避免把单一相关性直接写成根因。T12 明确采用只读指标、趋势、对照组和停止条件，T15 拒绝直接给出高风险生产写操作，说明安全边界有效。

### 5.3 题库工具链

T09 记录了题库生成成功，章节为 AIOps 第 07 章，题型和难度符合输入要求，并返回 quiz_id。T10 记录了判分工具返回的 0/3 成绩、逐题结果和复习建议。0/3 是学生提交答案的成绩，不是工具失败；工具链功能判定为通过。

### 5.4 异常输入与范围外处理

T07 能识别非法 PromQL 并指出具体语法问题，没有伪造执行结果。T14 和 T15 能识别知识库边界，其中 T15 进一步遵守高风险操作防护要求。

## 6. 优化前后对比

原始 T01–T15 文件提供了优化后模型的真实输出，基线文件提供了同输入的优化前输出。本报告将前后对比范围限定为 T01–T05，重点观察课程知识依据、引用质量、综合分析和 PromQL 解释差异。

### 6.1 优化前基线的执行方法

已收到的基线记录显示，测试使用基础模型 deepseek-v4-flash-ga-260731，未出现 Citation 或工具调用记录。基线配置要求如下：

1. 不绑定 AIOps 知识库；
2. 不勾选 python-course-quiz 和 python-course-rag；
3. 不使用本项目的 AIOps 系统提示词，只保留空白提示词或最小通用提示词；
4. 使用与优化后测试完全相同的模型 deepseek-v4-flash-ga-260731；
5. 按 T01–T05 原顺序逐条发送完全相同的测试输入；
6. 每条保存完整回答；如果模型声称有资料依据，也原样记录，但不要人为补充 Citation；
7. 本次已合并保存为 baseline-T01-T05-actual-evidence.md。

对照时重点记录：是否引用课程资料、是否调用工具、是否能识别知识库范围外问题、是否给出高风险生产命令、回答是否结构化，以及是否能完成题目生成和判分。不要改变测试输入、模型 ID 或测试顺序，否则不能作为严格的前后对比。

### 6.2 T01–T05 具体对比

| 用例 | 优化前基线 | 优化后模型 | 具体差异与结论 |
| --- | --- | --- | --- |
| T01 | 给出通用 SLO/错误预算解释，无课程 Citation | 引用 02-sre-observability.md，并区分资料原文、类比和推断 | 优化后增加可追溯课程依据，结论更适合课程验收 |
| T02 | 正确解释四大黄金信号，但无课程引用 | 引用黄金信号和案例资料，并明确补充解释范围 | 优化后可核验性更强，减少把补充知识误当资料原文的风险 |
| T03 | 将第一步概括为止血、回滚/扩容/抑制告警 | 明确“先聚合再分析”，按时间窗、拓扑和文本相似度压缩告警 | 优化后更符合课程根因分析流程，也更避免未经证据直接执行写操作 |
| T04 | 给出较长的通用故障排查方案，声称结合 AIOps 知识库但无 Citation，包含回滚/扩容等动作建议 | 按事实、候选根因、反证、只读证据和安全顺序组织，并明确写操作需审批 | 优化后证据链和安全边界更清楚；基线的“结合知识库”属于无引用表述 |
| T05 | 给出正确 PromQL 示例，但没有资料依据或工具证据 | 给出正确 PromQL，并明确具体语法属于通用补充知识、课程资料未完整展开 | 两者功能答案基本一致；优化后资料边界更诚实，因此仍判部分通过 |

基于上述前五条对比，优化后的主要提升是：课程知识库引用、事实与推断区分、根因分析结构和高风险操作边界。T05 说明知识库覆盖范围仍需在报告中如实标注。

当前可确认的优化后变化包括：

## 9. 最终评价

本项目已完成 AIOps 课程助教的核心人工功能验证：能够基于 AIOps 知识库进行课程问答和综合分析，能够识别资料范围外问题，能够调用题库工具完成练习题生成与判分，并能够在异常输入和高风险生产操作场景下保持安全边界。

在交付材料层面，建议将本报告与 T01–T15 原始输出、T01–T05 基线原文一并提交，并继续补充代表性 UI Citation、工具调用日志和测试环境信息。除 T05 因课程资料未展开具体 PromQL 语法而判定为部分通过外，当前 15 条人工测试没有发现功能性不通过项。
