# AIOps 智能运维课程助教项目总结报告

## 1. 项目概述

本项目基于 Open WebUI 与 DeepSeek，建设面向 AIOps 智能运维课程的专属 AI 助教。系统围绕课程知识问答、知识库引用、故障诊断、练习题生成、自动判分和安全边界控制展开，服务对象为正在学习 AIOps、SRE、可观测性、事故管理和大模型运维的学生。

当前课程模型使用 DeepSeek 模型 deepseek-v4-flash-ga-260731，绑定 AIOps 智能运维知识库，并接入题库与检索两个工具服务。

## 2. 项目目标

- 建立按 AIOps 知识模块组织的课程知识库；
- 让模型优先依据课程资料回答并提供 Citation；
- 支持可观测性、告警治理、根因分析和事故复盘等课程问答；
- 支持 AIOps 章节练习题生成、答案判分和复习建议；
- 对资料未覆盖问题明确说明，不伪造依据；
- 对生产环境高风险操作坚持只读分析、人工审批和回滚准备；
- 形成可复核的系统测试和最终交付材料。

## 3. 系统组成

| 组件 | 作用 |
| --- | --- |
| Open WebUI | 提供模型配置、知识库、聊天和 Citation 展示 |
| DeepSeek | 负责课程解释、分析和回答生成 |
| AIOps 知识库 | 覆盖 AIOps 基础、SRE、可观测性、异常检测、根因分析、事故管理、LLM4Ops 和工具生态 |
| 题库工具服务 | 提供按章节、难度、题型抽题和自动判分 |
| RAG 工具服务 | 提供轻量检索和课程资料快速查询 |
| 课程系统提示词 | 约束先检索后回答、资料边界、安全操作和学习辅导边界 |

工具服务采用 FastAPI 实现，但工具实现语言不改变课程测试方向；本项目最终测试主题为 AIOps。

## 4. 已实现能力

### 4.1 课程知识问答

系统能够围绕 SLO、错误预算、黄金信号、告警风暴、PromQL、LLM4Ops 等主题组织课程回答，并在回答中区分资料事实、合理推断和实践建议。

### 4.2 综合故障分析

系统能够按照“现象—可能原因—待验证证据—排查顺序—后续建议”分析延迟、错误率、吞吐量、连接池、数据库、缓存和发布变更等故障线索。

### 4.3 题库工具链

题库工具支持 AIOps 第 07 章和第 08 章。测试中 T09 成功生成第 07 章 3 道 beginner 单选题，T10 成功返回总分、逐题结果和复习建议。

### 4.4 范围外与安全边界

T14 对知识库未覆盖的 Zabbix 具体配置明确拒绝伪造生产参数。T15 对删除 Pod、修改副本数和关闭告警抑制等高风险写操作拒绝直接给出执行命令，转为只读核查和审批前置条件。

## 5. 系统测试结果

T01–T15 共 15 条人工系统测试结果如下：

| 结果 | 数量 |
| --- | ---: |
| 通过 | 14 |
| 部分通过 | 1 |
| 不通过 | 0 |

严格通过率为 14/15，即 93.3%；若将 T05 的资料覆盖不足视为可用但需说明边界，则功能可用率为 15/15，即 100%。

T05 的 PromQL 计算逻辑正确，但课程资料未完整展开具体 PromQL 语法，因此报告将其判定为部分通过，并要求明确标注通用知识来源。

优化前后对比使用 T01–T05。基线模型无知识库、无工具和无课程系统提示词；优化后模型增加了 AIOps 课程引用、结构化分析、范围外识别和安全边界控制。具体证据见系统测试报告和 evidence 目录。

## 7. 项目限制与后续建议

1. T05 的 PromQL 具体语法未完整收录在课程资料中，后续可补充经验证的课程示例。
2. 当前保留的是代表性 Citation 截图，若需要更强审计性，可继续补充每条测试的 Citation 展开截图或 JSON。
3. T09/T10 已有工具结果文字证据，建议最终提交时附上完整工具请求、响应和 quiz_id。
4. 正式报告中的测试环境、测试时间和测试人员信息仍需在提交前补齐。
5. 若课程要求量化优化收益，可继续补充 T01–T05 的评分维度，如引用准确性、事实正确性、结构完整性和安全性。

## 8. 最终评价

本项目已完成 AIOps 课程助教的核心建设和人工系统测试。系统能够利用 AIOps 知识库回答课程问题，进行故障与事故综合分析，调用题库工具生成和批改练习题，并在知识库无答案和高风险生产操作场景下保持透明、安全的响应边界。

综合评价为：核心功能满足课程助教交付目标，人工测试无功能性不通过项；T05 存在课程资料覆盖不足，已在正式报告中如实披露。
