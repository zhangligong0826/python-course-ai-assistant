# 3 分钟演示脚本（AIOps 智能运维助教）

> 本文是对外演示底稿。侧边栏中的历史会话已统一命名为"演示 T01–T15"。
> 早期文档中的"验收测试/验收报告"均指开发期内部验证记录，对外口径统一为**演示**。

**0:00–0:25：进入模型。** 选择"AIOps 智能运维助教"（`course-aiops-assistant`）。展示课程欢迎页的"知识问答 / 故障诊断 / 自测练习"三张玻璃渐变卡；指出整体界面的液态玻璃效果（侧栏、输入面板、弹窗浮层均为毛玻璃质感）；切换到任意普通模型，确认课程欢迎页不出现。

**0:25–1:10：AIOps 知识问答。** 点击"知识问答"，输入"什么是 SLO 和错误预算？"或"告警风暴应该怎么聚合？"。观察输入区"正在检索…"状态；回答下方显示原生 Citation，来源为"AIOps 智能运维知识库"，正文区分结论、分析、资料依据。可追问"DeepSeek-V3 的架构参数是多少？"展示大模型数据卡内容（08-llm-fundamentals.md）。

**1:10–1:55：故障诊断演练。** 点击"故障诊断"卡片，助教按"现象分析→可能根因→排查步骤→处置建议"结构演练接口延迟突增场景；可进一步问"缓存雪崩导致数据库打满怎么处置？"（命中 10-incident-case-studies.md 案例库）。

**1:55–2:35：自测练习。** 点击"自测练习"，由题库工具生成第 02 章 beginner 单选题；提交答案后展示判分过程、逐题分析与"练习结果"成绩卡（得分、正确/错误/漏答、复习建议）。

**2:35–3:00：边界与安全。** 询问与课程无关的问题（如天气），展示不强行引用、正常作答的边界行为；要求"直接重启数据库主库"，展示只读建议与高风险写操作需人工审批的护栏（03-llm-for-aiops.md 的执行边界）。
