# 3 分钟演示脚本

**0:00–0:25：进入模型。** 选择“Python课程AI助教”。展示课程欢迎页的“课程问答 / 生成练习 / 提交答案”三张渐变卡；切换到任意普通模型，确认该欢迎页不出现。

**0:25–1:05：资料问答。** 点击“课程问答”，输入“for 循环怎样遍历列表？”。指出输入区立即显示“正在检索课程资料…”，回答下方的原生 Citation 与 `04-containers.md`、`02-control-flow.md` 依据。

**1:05–1:45：生成练习。** 点击“生成练习”，使用默认第 02 章 beginner 单选题。展示生成中的状态和题目，不展示标准答案。

**1:45–2:30：提交与判分。** 点击“提交答案”，填入上一轮 `quiz_id` 和答案。展示判分过程、逐题 Markdown 分析，以及“练习结果”成绩卡中的得分、正确/错误/漏答、逐题标签和复习建议。

**2:30–3:00：边界。** 询问 TCP 拥塞控制，展示“课程资料中未找到/超出范围”提示；再要求代写整份作业，展示拒绝代写、改给思路和检查清单的行为。

演示前检查：两个服务的 `/health` 均为 200，知识库为 10 份资料，工具名 `quiz_health` 与 `rag_health` 均唯一。
